    Chave da YouTube Data API

    A chave é gratuita e fica salva só neste navegador. Cota diária de 10.000 unidades; cada atualização de canal gasta cerca de 3 a 5.

    1. Entre no Google Cloud com sua conta Google e crie um projeto (qualquer nome, ex. hora-do-desenho).
    2. Ative a API no projeto: Ativar YouTube Data API v3
    3. Crie a chave em Criar credenciais → Chave de API: Abrir página de credenciais
    4. Copie a chave (começa com AIza), cole abaixo e clique em Testar. Depois, em "Restringir chave", limite ao YouTube Data API v3 e ao seu domínio.

        Comportamento

        Este aparelho

        Na TV, a Hora do Desenho pode ser a tela inicial: a criança liga a TV e já cai nela. No celular, deixe desligado.

        Depois de ligar, aperte o botão HOME do controle e escolha "Hora do Desenho" → "Sempre". Para desfazer, desligue aqui ou use Configurações → Apps → Hora do Desenho → Limpar padrões.

        Horários de bloqueio

        Nesses horários a TV inteira dorme: nenhum canal toca e aparece o Dodó dormindo. Serve para a noite, a hora do almoço ou a soneca da tarde. Os pais podem liberar com o PIN.
